# ship-trial

Claude Ship（`/ship` コマンド）の限定試用専用リポジトリ。小さな Python プロジェクト＋pytest の CI で、/ship の一連の動き（PR 作成 → レビュー → CI 失敗や指摘への自動修正 → 人間がマージ）を安全に確かめるための場所。

## 試用の進め方

1. sheringham0809 がコラボレーター招待を承認する
2. win-g-white の Claude Code でこのリポジトリを開き、`gh auth status` で自分のアカウントのログインを確認する
3. 小さな変更を加えて `/ship` を実行する
4. PR が作られ、CI とレビューの様子、自動修正が入るかを見る。マージは人間が行う

## 判定基準（4週間または5 PR の早い方）

- CI・コンフリクトの自動解消が 2 件以上
- 誤った修正が 0 件
- Claude の使用枠を圧迫しない

を満たせば継続、満たさなければ撤去する。
